# 👁️ 30 Days of Computer Vision Challenge

Welcome to my 30-Day Computer Vision journey! I am Lina, a Computer and Network Engineering graduate. This repository documents my daily progress in mastering Computer Vision, bridging the gap between software algorithms, deep learning, and hardware deployment.

## 🎯 Challenge Goals
- **Fundamentals:** Master OpenCV for image processing and feature extraction.
- **Deep Learning:** Implement and train state-of-the-art models like YOLOv8 for object detection and segmentation.
- **Edge AI & Networks:** Optimize vision pipelines for real-time inference on embedded systems and understand the underlying network of vision data streams.
